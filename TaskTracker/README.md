# TaskTracker

TaskTracker is a C++ project built using CMake. It is designed to demonstrate a clean and modular C++ project structure with modern C++17 standard.

Project is implementation of Project : https://roadmap.sh/projects/task-tracker


## Building the Project
1. Prerequisites
    - C++ compiler supporting C++17 (e.g., g++ 9 or later)
    - CMake 3.20 or above

2. Build the project with following steps :

    ```bash
    mkdir build
    cd build
    cmake ..
    cmake --build .
    ```
3. Run project 

    ```bash
    ./TaskTracker
    ```
